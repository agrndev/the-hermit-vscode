## About
The Hermit uses a soft, carefully balanced palette with subtle color variations to reduce visual noise while keeping syntax clear and easy to understand. The goal is a coding environment that stays comfortable even after hours in the editor.

## Palette
<p align="center">

The palette is intentionally subtle, using gentle variations between colors rather than highly saturated contrasts.

## Installation

### From VSIX

1. Download the latest `.vsix` file from the **Releases** section.
2. Open **Visual Studio Code**.
3. Open the **Extensions** view.
4. Click the `...` menu.
5. Select **Install from VSIX...**.
6. Select the downloaded `.vsix` file.
7. Once installed, open the Command Palette and select **Preferences: Color Theme**.
8. Choose **The Hermit**.
